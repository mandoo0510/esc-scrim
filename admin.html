Admin

방송 화면 주소 · 팀 로고 · 라운드 수를 관리해요.

OBS 방송 화면

배경이 반투명한 순위표예요. 주소를 OBS · 프릭샷의 브라우저(웹) 소스에 넣으면 시트 점수가 자동으로 바뀌어요.

미리보기
설정 · 소스 추가 → 브라우저(웹) → URL에 붙여넣기 → 너비 340, 높이 700 (16팀 기준, 크기를 키웠다면 그만큼 늘려 주세요).
주소를 바꾼 뒤엔 소스에서 새 주소로 바꿔 넣으면 바로 최신 화면이 떠요.

팀 로고

팀을 고르고 이미지를 올리면 리더보드와 방송 화면에 바로 표시돼요. 정사각형 PNG(배경 투명)가 가장 깔끔해요.

시트 설정

스크림을 몇 라운드까지 진행할지 정해요. 바꾸면 구글 시트의 점수판 · 리더보드 · 랜드마크 · 최종순위 탭이 새 라운드 수로 다시 만들어지고, 사이트와 방송 화면의 매치 수도 같이 바뀌어요.

불러오는 중…
늘릴 때 · 새 라운드가 점수판 오른쪽에 추가되고, 점수는 마지막 라운드 포인트 표를 같이 써요 (예: 3,4,5 ROUND). 포인트는 시트의 라운드별 포인트 표에서 바로 고칠 수 있어요.
줄일 때 · 없어지는 라운드에 입력한 순위 · 킬은 지워져요.
입력해 둔 팀 이름 · 점수 · 추첨 결과 · 라운드 제목(맵 이름)은 그대로 유지돼요. 적용에 20~40초 걸려요.

관리자 계정

최초 관리자만 볼 수 있어요. 계정을 만들어 아이디와 비밀번호를 전달해 주세요. 지운 계정은 바로 로그아웃돼요.
